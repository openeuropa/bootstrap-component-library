# Accessibility findings by component

Initial WCAG 2.2 A/AA audit, 23 September 2026. Source review and scans of all **466 snapshot variants** found the issues below. See [snapshot results](accessibility-snapshots.md) for the four additional automated findings.

Only identified problems are listed. The Featured media finding is a best-practice advisory. Browser, visual, keyboard and screen-reader checks remain pending.

## Components

| Name                                                 | Problem found                                                                                                                                       |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| [carousel](../src/components/bcl-carousel)           | Previous/next buttons have no accessible name when labels are omitted (4.1.2). Autoplay has no pause control (2.2.2 requires browser verification). |
| [form-input](../src/components/bcl-form-input)       | Error message is not linked to the field; `invalid` adds no `aria-invalid` state (1.3.1; validation flow needs review).                             |
| [modal](../src/components/bcl-modal)                 | Dialog name is the generated ID rather than the title; supplied `aria-label` is overwritten (2.4.6, 4.1.2).                                         |
| [offcanvas](../src/components/bcl-offcanvas)         | Close button has no name when `close_aria_label` is omitted (confirmed in Group snapshot; 4.1.2).                                                   |
| [pagination-v2](../src/components/bcl-pagination-v2) | Custom-icon next link has no accessible name (snapshot-confirmed; 2.4.4 / 4.1.2).                                                                   |
| [pagination](../src/components/bcl-pagination)       | Custom-icon next link has no accessible name (snapshot-confirmed; 2.4.4 / 4.1.2).                                                                   |
| [select](../src/components/bcl-select)               | Help and error messages are not linked to the field; `invalid` adds no `aria-invalid` state (1.3.1; validation flow needs review).                  |
| [table](../src/components/bcl-table)                 | Header cells use `<td>` instead of `<th>` (1.3.1).                                                                                                  |
| [textarea](../src/components/bcl-textarea)           | Error message is not linked to the field; `invalid` adds no `aria-invalid` state (1.3.1; validation flow needs review).                             |
